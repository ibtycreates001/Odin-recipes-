# Odin Recipes

A multi-page recipe website built as part of **The Odin Project** curriculum, featuring step-by-step instructions and ingredients for some of my favorite dishes.

## Live Demo
Check out the live website here: [View Odin Recipes Live](https://ibtycreates001.github.io/Odin-recipes-/)

## Recipes Included
* **Jollof Rice** — Ingredients, preparation details, and cooking instructions
* **Jollof Pasta** — Ingredients, preparation details, and cooking instructions
* **Steak Cuts** — Guide and preparation steps for steak cuts

## Built With
* **HTML5** — Semantic page structure, lists, and multi-page navigation links

## What I Learned
Building and deploying this project helped me practice:
* Structuring multi-page websites with clean, semantic HTML
* Organizing files into folders and linking pages using relative paths
* Initializing a Git repository, committing changes, and pushing code to GitHub from mobile using **Spck Editor**
* Publishing a live static website using **GitHub Pages**
